# Amazon Cyber Threat Intelligence Investigation

## Overview

This project documents a Cyber Threat Intelligence investigation conducted using OpenCTI, with Amazon used as the simulated organization.

The investigation covered four areas:

1. Sector & Threat Landscape Profiling
2. Country-Level Threat Assessment
3. Victim & Threat Deep Dive
4. Political Threat Actor Analysis

## Tools & Frameworks

- OpenCTI
- MITRE ATT&CK
- Diamond Model
- Cyber Kill Chain
- Threat Intelligence analysis
- Victimology analysis

## Key Investigations

- ModeloRAT
- TraderTraitor
- Lazarus Group
- Operation Dream Job

## Project Scope

The investigation examined threats, threat actors, malware, campaigns, victims, relationships and attack techniques relevant to the simulated Amazon environment.

## Evidence

OpenCTI screenshots and investigation evidence are organized within the individual task folders.

## Disclaimer

Amazon was used as the simulated organization for this CTI exercise. OpenCTI relationships shown in this project should not automatically be interpreted as evidence of a real-world compromise of Amazon.
