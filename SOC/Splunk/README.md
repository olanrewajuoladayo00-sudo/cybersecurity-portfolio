# Splunk SOC Lab

## Overview

This project documents my hands-on experience using Splunk for Security Operations Center (SOC) monitoring and security event analysis.

## Objectives

- Configure and use Splunk for security monitoring
- Ingest and search security logs
- Identify suspicious activities
- Analyze security events
- Create basic detections and alerts
- Investigate security incidents

## Tools

- Splunk Enterprise
- Kali Linux
- Windows/Linux systems

## Skills Demonstrated

- SIEM monitoring
- Log analysis
- Threat detection
- Incident investigation
- Security event analysis
- SPL (Search Processing Language)
