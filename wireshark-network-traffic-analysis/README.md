# Wireshark Network Traffic Analysis

This project documents a defensive cybersecurity investigation using Wireshark.

## Project Details
- **Case:** CB-002 — Fictional training records
- **Tool:** Wireshark
- **Environment:** Kali Linux
- **Capture:** `week2-traffic.pcap`

## Objectives
- Analyze DNS queries and responses.
- Examine TCP connection establishment.
- Inspect HTTP request and response traffic.
- Identify TLS application data.
- Document findings and recommend further investigation.

## Evidence and Analysis
This folder contains the packet analysis, investigation findings, recommendations, and supporting Wireshark screenshots.

**Important:** This is a training exercise. The observations do not, by themselves, prove malware execution, system compromise, or data theft.
